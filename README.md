# CGPA Calculator 🎓

Calculate your semester GPA using the standard **Bangladesh UGC grading scale** — used by Southeast University (SEU) and most universities in Bangladesh.

## 🔗 Live Demo
👉 https://nafiz-xd.github.io/cgpa-calculator/

## ✨ Features
- Add as many courses as you need (course name, credits, grade)
- Instant GPA from total grade points ÷ total credits
- Built-in UGC grading scale reference (A+ = 4.00 … F = 0.00)
- Works for overall CGPA too — just enter every semester's courses

## 🛠️ Tech
HTML • CSS • JavaScript — single page, hosted on GitHub Pages.
